# Changelog & Updates Tracking

Whenever the user asks for updates, changelog, or when major features are completed:
1. Always update [UPDATES.md](file:///Volumes/Rob%20Buids/Website%20Projects/LABADAGO/UPDATES.md) located at the workspace root.
2. Chronologically append new entries under previous entries.
3. Always prefix the section with the current date in `YYYY-MM-DD` format (e.g., `## [YYYY-MM-DD]`).
4. Detail features and improvements concisely with bullet points.
